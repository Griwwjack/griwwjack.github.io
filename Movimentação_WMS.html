Favorito: Movimentação de Pallets WMS

Instalar

Movimentação WMS

  1. Mostre a barra de favoritos (Ctrl+Shift+B no Chrome/Edge/Firefox).
  2. Arraste o botão laranja acima para a barra.

Se o arrastar não funcionar

  1. Crie um favorito novo com o nome Movimentação WMS.
  2. No campo do endereço (URL), cole o texto abaixo.

Usar

Entre no SolWMS e, com a página aberta, clique no favorito. O painel abre; clicar de novo fecha.
Só funciona dentro do site do WMS (solwms-r4.refrio.com.br).
